# Puzzle illustrations

The first 50 puzzles in book order, plus the previously illustrated easy puzzles 51, 57, and 58. Warm, minimal cartoons show only each setup; independent reviews check them against the questions and solutions.

PNG originals remain local; the public WebP URLs and dimensions are recorded in `src/puzzlebook/data/illustrations.json`. Exact prompts and review notes are kept here.
