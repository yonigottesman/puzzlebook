# Puzzle illustrations

Twenty easy puzzles in book order, generated with the built-in image tool in a warm minimal cartoon style. Illustrations show only the setup; each was reviewed against the original question and solution.

Images are served from `puzzlebook-images-941271455567` in Cloud Storage. PNG originals remain local; public WebP URLs are recorded in `src/puzzlebook/data/illustrations.json`. Exact prompts and review notes are kept here.
